# Portfolio · Axel Jourdas

Portfolio d'étudiant en **BTS SIO option SISR** (Solutions d'Infrastructure, Systèmes et Réseaux), en alternance à MyDigitalSchool.

Le site est pensé comme une **baie réseau** : le menu est un panneau de brassage, chaque bloc est une façade d'équipement et chaque domaine a sa couleur de câble (bleu = réseau, rouge = sécurité, vert = système, orange = support).

## Contenu

- **9 projets documentés** : pare-feu pfSense et VPN, supervision Wazuh, durcissement Linux et Windows, GLPI, Active Directory, baie informatique, CTF, TryHackMe
- **Compétences** reliées aux projets qui les prouvent
- **Tableau de synthèse** des réalisations pour le BTS
- **Veille informatique** mise à jour automatiquement à partir de flux RSS

## Technique

- HTML, CSS et JavaScript, sans framework ni étape de compilation
- Thème sombre « baie noire » et thème clair « baie grise »
- Responsive (mobile, tablette, ordinateur)
- Hébergé sur GitHub Pages

## Lancer le site en local (Windows)

Double-cliquer sur `Lancer le portfolio.bat` : le site s'ouvre sur `http://localhost:8080`.
